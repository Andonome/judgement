\subsubsection{\Glsfmttext{weight}}
usually increases when \gls{equipment} has larger bonuses.
So \pgls{weapon} might have any Attack Bonus, but the larger the Bonus, the larger the \gls{weight}.

Round all results down, so $5.9 = 5$.

\index{Armour!Formula}
\index{Weapons!Formula}

\[
  \mbox{ Armour \glsentrytext{weight} } = \mbox{ \glsentrytext{dr} } + \frac{\mbox{ \glsentrytext{covering} }}{2} - 3
\]

\[
  \mbox{ Weapon \glsentrytext{weight} } = \frac{ | \mbox{ Bonus } | + \max \{ 0, \mbox{ Damage } \} } { 2 }
\]

\subsubsection{\Glsfmtlongpl{cr}}
are made of two numbers: an `attack-rating', and `defence-rating'.
The two are added together, and divided by 10, just to make the numbers smaller.
This cheap estimation has no more authority or accuracy than a semi-educated guess, so if you make your own \glspl{npc}, and you want to give them \pgls{cr}, it's better to go with your gut than your calculator.

\end{multicols}

\[
  \mbox{ \glsentrytext{cr} } = \frac{
  ( \mbox{ \glsentrytext{tn} } - \mbox{ \glsentrytext{ap} cost } ) \times ( \mbox{ Damage Total } + \mbox{ \glsentrytext{ap} } )
  +
  ( \mbox{ \glsentrytext{dr} } + 1 ) \times ( \mbox{ \glsentrytext{hp} } + \mbox{ \glsentrytext{mp} } )
  - 40
  } {10}
\]

  \noindent
  Various events and items can boost spells, whether cast through \pgls{skill}, or \gls{alchemy}.
  Each boon has a symbol showing whether it comes from an animal (`\A'), or a plant (`\Pl').
  Others (`\glsentrytext{R}') indicate meteorological events which give a boost to \Pgls{sphere}.
  These meteorological events, and \glspl{boon} made from \pgls{ingredient} each add +1 to \pgls{skill} \gls{sphere}, but only one of each can apply; i.e. to get +2 to the Fire \gls{sphere}, one needs to use a bear's heart during a heatwave, but many bear-hearts will not help.

  \Glspl{ingredient} taken from plants or the bodies of beasts can spoil quickly, depending on the \gls{cycle}'s temperature.

  The \glsentrytext{deep} remains cold all year round, so it always counts as a cold season down there.
  \end{multicols}
